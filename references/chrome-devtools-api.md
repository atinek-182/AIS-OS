# Chrome DevTools MCP API Reference

Interacts with Chrome browser tabs to audit performance and accessibility.

## Tools
- `chrome-devtools-mcp/lighthouse_audit`: Run SEO/Perf audits.
- `chrome-devtools-mcp/list_console_messages`: Read page console logs.
- `chrome-devtools-mcp/take_screenshot`: Capture viewport.
