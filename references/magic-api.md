# Magic MCP API Reference

Sourcing Tailwind/React components and search brand logos.

## Tools
- `magic/21st_magic_component_builder`: Sourced mockup generator.
- `magic/logo_search`: Query brand logo assets.
- `magic/21st_magic_component_inspiration`: Find design patterns.

## Authentication
Uses `API_KEY` environment variable.
