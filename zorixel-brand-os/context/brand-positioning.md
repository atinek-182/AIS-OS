# ZORIXEL Brand Positioning & Identity Spec

## 1. Brand Identity
- **Brand Name**: ZORIXEL
- **Founder**: Atinek Maurya
- **Tagline**: The AI-Powered Web Design & Engineering Studio
- **Core Mission**: Empower UI designers, freelancers, and vibe coders to build agency-quality web experiences and sellable AI automations using modern tools and AI OS workflows.

## 2. Target Audience Segments
1. **Aspiring & Practicing Web Designers / Freelancers**: Want to level up visual design taste, speed up builds, and close $1.5k–$3k+ client projects.
2. **Beginner Frontend Developers & Vibe Coders**: Want clean component patterns, GSAP/WebGL animations, and production Next.js/Tailwind architectures without getting bogged down in boilerplate.
3. **Solopreneurs & AI Tool Builders**: Want to automate research, content production, and task management using local AI OS setups.

## 3. Brand Aesthetic & Visual Standards
- **Color Philosophy**: Modern dark mode with OKLCH tokens, vibrant accent gradients, and WCAG AA compliance.
- **Typography**: Premium typography pairs (e.g. `Rosehot` / `Nuqun` for headings, `Outfit` / `Inter` for body).
- **Visuals**: Dynamic micro-graphics, 16:9 canvas slides, clean 3D stage elements, and real UI code snippets.
