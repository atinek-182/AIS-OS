## Capabilities & Usage Guide

The skill is powered by the Python runner script at `scripts/composio_runner.py` and the global CLI binary `composio`.

### 1. Search 1000+ App Tools by Natural Language
```powershell
python scripts/composio_runner.py search --query "create linear issue"
python scripts/composio_runner.py search --query "send slack message"
```

### 2. Connect an Account via Managed OAuth Link
```powershell
python scripts/composio_runner.py link --app hubspot
python scripts/composio_runner.py link --app linear
```

### 3. Execute a Tool Action with JSON Data
```powershell
python scripts/composio_runner.py execute --tool LINEAR_CREATE_ISSUE --data '{"title":"Bug fix","team_id":"123"}'
```

### 4. Verify Authentication & User Context
```powershell
python scripts/composio_runner.py whoami
```
