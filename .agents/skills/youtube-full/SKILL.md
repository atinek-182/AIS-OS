## Architecture & Dual-Backend Fallback Routing

The skill operates via `scripts/youtube_skills_runner.py`:

1. **Primary Backend (Local `yt-dlp`)**:
   - **Cost**: 100% Free, Unlimited, zero token cost.
   - **Execution**: Runs locally on Windows OS using Node JS runtime (`--js-runtimes node`).
   - Handles video transcript metadata extraction, subtitles, auto-captions, channel video lists, and playlist dumps.

2. **Fallback Backend (`TranscriptAPI.com`)**:
   - Triggered automatically if local `yt-dlp` suffers an IP rate-limit or anti-bot block.
   - Requires `$TRANSCRIPT_API_KEY` (Free tier gives 100 credits on signup at [TranscriptAPI.com](https://transcriptapi.com)).

---

## Capabilities & Usage Guide

### 1. Extract Video Transcript & Subtitles
```powershell
python scripts/youtube_skills_runner.py transcript --url "https://www.youtube.com/watch?v=VIDEO_ID"
```

### 2. Search YouTube Videos by Query
```powershell
python scripts/youtube_skills_runner.py search --query "AI workflow automations" --max-results 5
```

### 3. Extract Videos from a Playlist
```powershell
python scripts/youtube_skills_runner.py playlist --url "https://www.youtube.com/playlist?list=PLAYLIST_ID"
```
